# Energy Usage Monitoring & Reporting System

> Turning a messy pile of spreadsheets into a real, reliable reporting system.

## The Problem

Picture an entire energy resource department running on Excel sheets. Dozens of them. Data entered by hand, day after day, with the same values copied, re-copied, and duplicated across files.

There was no single source of truth and no easy way to spot trends. Just a growing pile of spreadsheets that got harder to trust with every update.

## The Solution

Instead of patching the spreadsheet chaos, we replaced it with a desktop application built to think like a real database, not a filing cabinet.

Here's what went into making that happen:

- **Understood the data first.** We dug into how the raw energy data actually flowed and repeated across sheets before touching any code.
- **Killed the duplication.** Redundant entries were identified and cleaned out at the source instead of being copied forward.
- **Normalized everything.** The data was restructured into a clean, consistent, logical format.
- **Built a server-friendly database.** The schema was designed to be efficient and scalable, ready for real reporting rather than just storage.

The result is a system that quietly handles the tedious, error-prone work automatically, so the reports it produces are something people can actually trust and act on.
